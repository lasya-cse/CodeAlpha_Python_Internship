# Task 4 - Basic Chatbot
## 📌 Project Overview
The Basic Chatbot is a simple rule-based chatbot developed using Python as part of the CodeAlpha Python Programming Internship. The chatbot interacts with users through the console and provides predefined responses based on the user's input.
## 🎯 Objective
The objective of this project is to create a simple interactive chatbot while demonstrating basic Python programming concepts such as input/output, conditional statements, functions, and loops.
## ✨ Features
- Simple console-based chatbot
- Accepts user input
- Provides predefined responses
- Recognizes greetings such as hello, hi, and hey
- Responds to "how are you"
- Provides information about the chatbot
- Provides basic help
- Handles unknown messages
- Supports goodbye messages
- Continues conversation until the user exits
## 🛠️ Technologies Used
- Python 3
- Input/Output
- If-Else Statements
- Functions
- While Loop
- Strings
- String Methods
## 💬 Supported Conversations
| User Input | Chatbot Response |
|---|---|
| hello | Hi! How can I help you? |
| hi | Hi! How can I help you? |
| how are you | I'm fine, thanks! |
| what is your name | I'm a Basic Python Chatbot. |
| who are you | I am a simple rule-based chatbot created using Python. |
| help | Provides basic usage information |
| bye | Goodbye! Have a great day! |
| goodbye | Goodbye! Have a great day! |
## ⚙️ How It Works
1. The program starts the chatbot.
2. The user enters a message through the console.
3. The input is converted to lowercase for easy comparison.
4. The program checks the input using `if-elif-else` conditions.
5. A predefined response is selected.
6. The chatbot displays the response.
7. The conversation continues using a `while` loop.
8. When the user enters `bye` or `goodbye`, the chatbot ends the conversation.
